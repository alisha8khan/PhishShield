# PhishShield

A phishing URL detection project using machine learning to classify websites as phishing or legitimate.

## About the Project

Phishing is a common cyber attack where attackers create fake websites or URLs to trick users into sharing sensitive information such as usernames, passwords, and banking details.

PhishShield analyzes URL features and uses machine learning models to identify whether a URL is potentially phishing or legitimate.

## Features

1. Phishing URL detection
2. URL feature extraction
3. Machine learning-based classification
4. Web-based URL scanner
5. Simple and user-friendly interface
6. Safe and potentially unsafe URL results

## Machine Learning Models

The project explores different machine learning models, including:

1. Logistic Regression
2. k-Nearest Neighbors 
3. Support Vector Clasifier
4. Naive Bayes
5. Decision Tree
6. Random Forest
7. Gradient Boosting
8. Catboost
9. Xgboost
10. Multilayer Perceptrons

## Dataset

The dataset used in this project was obtained from Kaggle.

It contains 11,054 website URLs with different URL-related features and a class label used to identify **phishing and legitimate websites**.

The dataset file is not included in this repository.

Dataset Source: https://www.kaggle.com/eswarchandt/phishing-website-detector .
